# Calculation programm
## Workflow
1) Prints all available metals
2) User have to choose material to proceed with
3) After that user have to provide 4 parameters
   - List length
   - List width
   - List thickness
   - Quantity
4) Programm returns:
   - Used material
   - Mass of all lists
   - Thickness class

## Used formula
Mass = Length * Width * (Thickness / 1000) * Density * Quantity
